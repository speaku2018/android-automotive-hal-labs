# Android Automotive HAL labs

Source projects for the hands-on lessons in **Android Automotive HAL Development: AIDL VHAL & Labs**. These examples target the AAOS 15 / AOSP reference environment used in the course. Follow each project's own README for build and integration steps.

| Folder | Lesson |
|---|---|
| [`01-vehicle-speed-reader`](01-vehicle-speed-reader/) | Create a live AAOS vehicle speedometer |
| [`02-cabin-temperature-control-app`](02-cabin-temperature-control-app/) | Build an AAOS cabin-temperature control app |
| [`03-helloworld-aidl-hal`](03-helloworld-aidl-hal/) | Build a standalone HelloWorld AIDL HAL service |
| [`04-helloworld-rtc-hal`](04-helloworld-rtc-hal/) | Connect HelloWorld HAL to the Linux RTC driver |

The folders contain the extracted source projects from the course's `project.zip` downloads. The RTC build evidence log and the lecture video production bundle are not included.
